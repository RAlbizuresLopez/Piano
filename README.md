# Piano — profesor personal de música

Repositorio de métodos pedagógicos, ejercicios y progreso del estudio de piano.

## Skills
- [profesor-musica](skills/profesor-musica/SKILL.md): coordinación del pensum y las sesiones.
- [tecnica-pianistica](skills/tecnica-pianistica/SKILL.md): técnica y ejecución.
- [lectura-solfeo](skills/lectura-solfeo/SKILL.md): lectura y ritmo.
- [entrenamiento-auditivo](skills/entrenamiento-auditivo/SKILL.md): escucha y reconocimiento.
- [dictado-musical](skills/dictado-musical/SKILL.md): transcripción.
- [laboratorio-armonia](skills/laboratorio-armonia/SKILL.md): escalas, acordes y conducción.
- [analisis-musical](skills/analisis-musical/SKILL.md): análisis de repertorio.
- [repertorio-piano](skills/repertorio-piano/SKILL.md): estudio de piezas.
- [composicion-musical](skills/composicion-musical/SKILL.md): creación e improvisación.
- [evaluacion-progreso](skills/evaluacion-progreso/SKILL.md): evidencias y seguimiento.
- [cuaderno-musical](skills/cuaderno-musical/SKILL.md): guardado y recuperación.

## Reglas de trabajo
Una actividad por turno; esperar el intento antes de dar soluciones. No inferir destreza práctica a partir de teoría. Instrumento: Thomann SP-5600, 88 teclas, acción de martillo, sensibilidad dinámica y sustain (medio pedal no verificado). Usar las herramientas de audio/partitura disponibles; registrar únicamente evidencias reales.

## Organización
`skills/`: métodos; `progreso/`: evaluaciones verificadas; `ejercicios/`: enunciados y soluciones separados; `repertorio/`: piezas y anotaciones; `sesiones/`: resúmenes.

Estas skills en GitHub son archivos de referencia: no se instalan automáticamente en ChatGPT. Para utilizarlas, hay que incorporarlas a las instrucciones o archivos del proyecto, o disponer de un mecanismo que las lea.
